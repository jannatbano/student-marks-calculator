# Student Marks Calculator

A beginner Python project that takes student information and marks for four subjects, then calculates the total marks, percentage, and grade.

## Features
- Takes student name and class as input
- Takes marks for Python, Java, C, and HTML
- Calculates total marks
- Calculates percentage
- Displays grade based on percentage

## Technologies Used
- Python

## How to Run
1. Download or clone the project.
2. Open the file in VS Code.
3. Run the program using Python.
4. Enter the student details and marks.
